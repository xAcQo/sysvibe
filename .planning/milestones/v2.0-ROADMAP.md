## Phase 5: Go Language Pack

**Goal:** Build the Go language pack with idiomatic rules and golangci-lint quality gates.

**Requirements:** GO-01, GO-02, GO-03, GO-04

**Success Criteria:**
1. `sysvibe init --template go` scaffolds a Go module project
2. Agent config includes idiomatic Go rules (error handling, concurrency)
3. `sysvibe check` runs `golangci-lint`, `go vet`, and `go test -race`

**Depends on:** Phase 4 (v1.0 complete)

---

## Phase 6: Zig Language Pack

**Goal:** Build the Zig language pack with strict comptime and allocator rules.

**Requirements:** ZIG-01, ZIG-02, ZIG-03, ZIG-04

**Success Criteria:**
1. `sysvibe init --template zig` scaffolds a `build.zig` project
2. Agent config includes Zig rules (error unions, allocators, comptime)
3. `sysvibe check` runs `zig build test` and `zig fmt --check`

**Depends on:** Phase 4

---

## Phase 7: C Language Pack

**Goal:** Build the C language pack with strict C11/C17 enforcement.

**Requirements:** C-01, C-02, C-03

**Success Criteria:**
1. `sysvibe init --template c` scaffolds a CMake project for C
2. Agent config enforces strict memory management and C17 standards
3. `sysvibe check` enforces `-Wall -Werror -std=c17`

**Depends on:** Phase 4

---

## Phase 8: Advanced CLI Features

**Goal:** Add `sysvibe eject`, custom gate definitions, and combo pack support.

**Requirements:** ADV-01, ADV-02, ADV-03

**Success Criteria:**
1. `sysvibe eject` cleanly removes all `<!-- SYSVIBE START -->` blocks from agent config
2. Users can define custom gates in `.sysvibe.toml`
3. Support initializing multi-language combo projects (e.g. C++ with Python bindings)

**Depends on:** Phase 5, Phase 6, Phase 7
