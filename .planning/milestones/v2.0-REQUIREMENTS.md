# Requirements: SysVibe v2.0

**Defined:** 2026-05-07
**Core Value:** AI-generated systems language code must meet production-grade quality standards

## v2 Requirements

### Go Language Pack

- [x] **GO-01**: Go pack includes idiomatic rules (error handling, concurrency)
- [x] **GO-02**: Go pack includes quality gate: `golangci-lint`
- [x] **GO-03**: Go pack includes quality gate: `go vet` and `-race` detector
- [x] **GO-04**: Go pack includes project template scaffolding (Go modules)

### Zig Language Pack

- [x] **ZIG-01**: Zig pack includes idiomatic rules (comptime, error unions, allocators)
- [x] **ZIG-02**: Zig pack includes quality gate: `zig build test`
- [x] **ZIG-03**: Zig pack includes quality gate: `zig fmt --check`
- [x] **ZIG-04**: Zig pack includes project template scaffolding (`build.zig`)

### C Language Pack

- [x] **C-01**: C pack includes idiomatic rules (strict C11/C17, memory management)
- [x] **C-02**: C pack enforces strict compiler flags (`-Wall -Werror -std=c17`)
- [x] **C-03**: C pack includes CMake project template scaffolding

### Advanced Features

- [x] **ADV-01**: `sysvibe eject` command to cleanly remove all SysVibe sections from agent configs
- [x] **ADV-02**: Custom quality gate definitions via `.sysvibe.toml`
- [x] **ADV-03**: Multi-language combo pack support (e.g., C++ with Python bindings via pybind11)

## Future Requirements (v3.0+)

- [ ] CI/CD integration templates (GitHub Actions, GitLab CI)
- [ ] Gate result caching (skip re-running unchanged files)

## Out of Scope

| Feature | Reason |
|---------|--------|
| IDE/editor plugins | SysVibe works through agent config files, not IDE extensions |
| Build system replacement | SysVibe invokes existing tools (CMake, Cargo, Zig), not replaces them |
| Web framework support | Other tools cover web; SysVibe is systems-only |
| GUI Agent Child Process Loop | GUI agents (Cursor) require developer-driven loops (`@.sysvibe/fix-prompt.md`) |
