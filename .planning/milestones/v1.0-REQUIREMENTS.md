# Requirements: SysVibe

**Defined:** 2026-05-07
**Core Value:** AI-generated systems language code must meet production-grade quality standards

## v1 Requirements

### CLI Core

- [ ] **CLI-01**: User can install SysVibe via `npx sysvibe` (one command, zero config)
- [ ] **CLI-02**: User can run `sysvibe init` to interactively select language packs
- [ ] **CLI-03**: User can run `sysvibe add <pack>` to add a language pack to an existing project
- [ ] **CLI-04**: User can run `sysvibe check` to execute the quality gate pipeline
- [ ] **CLI-05**: User can run `sysvibe fix` to auto-fix gate failures via AI agent feedback loop
- [ ] **CLI-06**: Per-project config stored in `.sysvibe.toml` tracks active packs and settings

### Agent Integration

- [ ] **AGENT-01**: SysVibe auto-detects which AI agent is active (Claude Code, Gemini CLI, Cursor, OpenClaw, Codex)
- [ ] **AGENT-02**: SysVibe generates the correct config file format per agent (CLAUDE.md, GEMINI.md, .cursorrules, AGENTS.md)
- [ ] **AGENT-03**: SysVibe appends to existing agent config files using section markers (never overwrites)
- [ ] **AGENT-04**: SysVibe generates a universal AGENTS.md alongside agent-specific files

### C++ Pack

- [ ] **CPP-01**: C++ pack includes idiomatic rules (smart pointers, RAII, modern C++17+, no raw new/delete)
- [ ] **CPP-02**: C++ pack includes anti-pattern list with explanations (what to never do and why)
- [ ] **CPP-03**: C++ pack includes quality gates: compile with -Wall -Werror -Wpedantic
- [ ] **CPP-04**: C++ pack includes quality gate: clang-tidy with modern checks
- [ ] **CPP-05**: C++ pack includes quality gate: AddressSanitizer (-fsanitize=address)
- [ ] **CPP-06**: C++ pack includes few-shot examples (AI-typical wrong pattern → correct pattern)
- [ ] **CPP-07**: C++ pack includes CMake project template scaffolding

### Rust Pack

- [ ] **RUST-01**: Rust pack includes idiomatic rules (proper error handling with ?, no excessive .unwrap())
- [ ] **RUST-02**: Rust pack includes anti-pattern list (excessive .clone(), unnecessary unsafe, C-style patterns)
- [ ] **RUST-03**: Rust pack includes quality gate: cargo clippy -- -D warnings
- [ ] **RUST-04**: Rust pack includes quality gate: cargo fmt --check
- [ ] **RUST-05**: Rust pack includes quality gate: cargo test --all-targets
- [ ] **RUST-06**: Rust pack includes few-shot examples (AI-typical wrong pattern → correct pattern)
- [ ] **RUST-07**: Rust pack includes Cargo project template scaffolding

### Quality Pipeline

- [ ] **GATE-01**: `sysvibe check` runs all gates in order: compile → lint → sanitize → test
- [ ] **GATE-02**: Each gate produces clear pass/fail output with human-readable error summaries
- [ ] **GATE-03**: Pipeline returns exit code 0 (all pass) or 1 (any fail) for CI integration
- [ ] **GATE-04**: Auto-fix loop captures gate failures, formats for AI agent, and triggers re-check
- [ ] **GATE-05**: Auto-fix loop tracks error hashes to prevent infinite retry cycles
- [ ] **GATE-06**: Auto-fix loop has configurable max retry count (default: 3)
- [ ] **GATE-07**: `sysvibe init` verifies toolchain availability and reports missing tools with install instructions

## v2 Requirements

### Additional Language Packs

- **GO-01**: Go language pack with golangci-lint, go vet, race detector
- **ZIG-01**: Zig language pack with zig build quality checks
- **C-01**: C language pack with strict C11/C17 standards enforcement

### Multi-Language Combos

- **COMBO-01**: C++ + Python combo pack (pybind11 patterns, FFI safety rules)
- **COMBO-02**: Rust + Python combo pack (PyO3 patterns, maturin integration)
- **COMBO-03**: C++ + Rust combo pack (FFI boundary safety checks)

### Advanced Features

- **ADV-01**: `sysvibe eject` cleanly removes all SysVibe sections from agent configs
- **ADV-02**: Custom gate definitions via `.sysvibe.toml` (user-defined quality checks)
- **ADV-03**: CI/CD integration templates (GitHub Actions, GitLab CI)
- **ADV-04**: Gate result caching (skip re-running unchanged files)

## Out of Scope

| Feature | Reason |
|---------|--------|
| IDE/editor plugins | SysVibe works through agent config files, not IDE extensions |
| Build system replacement | SysVibe invokes existing tools (CMake, Cargo), not replaces them |
| Language server | Not competing with clangd or rust-analyzer |
| Code formatting tool | Uses clang-format/rustfmt directly, just enforces they run |
| Dependency management | Not competing with Conan, vcpkg, or Cargo |
| Web framework support | Other tools cover web; SysVibe is systems-only |
| Model training/fine-tuning | Works at prompt/rules layer, not model layer |
